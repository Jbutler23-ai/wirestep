# Data and license

The example circuits, stimuli, and benchmark designs are synthetic. They contain no proprietary chip designs, device captures, personal data, credentials, or production system information.

The prototype reads local JSON and writes traces and reports. It makes no network requests and doesn't connect to physical devices. Development and regression cases should continue using small constructed circuits and generated designs with known expected behavior.

Reports include the supplied circuit description and signal values. They contain normalized circuit and stimulus digests, without absolute source paths or wall-clock timestamps.

The repository's code, documentation, and examples use the [MIT license](../LICENSE). There are no third-party runtime dependencies. Linked teaching materials are technical references and aren't bundled with the project.
